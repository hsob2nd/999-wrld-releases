# 999 WRLD

A Juice WRLD inspired music player for your own collection, with an equaliser, loudness matching, local radio, optional on-device AI DJ, playlists, and listening recaps.

**[Download app releases](https://github.com/hsob2nd/999-wrld-releases/releases)** · **[Report a bug or request a feature](https://github.com/hsob2nd/999-wrld-releases/issues/new/choose)**

This repository contains public app releases and issue reports. Application development source and build workflows are maintained in a separate private repository. There is no music collection, listening history, personal configuration, or credential data in this repository. Compiled app downloads naturally contain the runtime components needed to run the app.

## Platforms

- Windows: extract the portable ZIP into a folder, then open **999 WRLD.exe**. Keep its UserData folder with it. Future published Windows releases can be checked, downloaded, verified and installed from **Settings → Keep your WRLD up to date**.
- Android: download the APK and install through Android's package installer. Only install app releases from this repository. The current build uses a development signing key, so later builds may require reinstalling until a permanent release signing key is configured; export your playlists and settings first.
- iOS: the current downloadable app is an **iPhone simulator build for Xcode**, not an installable iPhone IPA. Physical iPhone distribution requires Apple signing and TestFlight or the App Store.

## Privacy and downloads

Local music stays on your device. Optional AI models download on request and run locally. Catalogue, lyrics source and public release checks contact their respective services. Original song downloads depend on catalogue availability and are limited to 60 MB per track.

When filing an issue, include the app version, platform, steps and the error message. Do not attach music files, personal listening history, access tokens or your UserData folder. Song titles and screenshots are optional; redact any private details.

This is an independent fan-made player, not an official artist product. Third-party music, artwork and trademarks remain with their respective owners.
